## Eyes-on review findings and what changed
1. Lookbook composed looks: title, status line and product list were near-invisible (paper ink on the dark island). Cause: `--sr2-ink` resolves where declared, so re-binding `--lb-ink` on the island did not re-bind `--sr2-ink`. Fixed in `lookbook.css` by binding both token sets on `.sr2-lookbook__look .sr2-world--hero-composed`, the Black Rose chapter and the closing. Verified `lookbook-section-1440-03.png`, `lookbook-section-390-02.png`.
2. Lookbook chapter index label sat in the headline column (`.sr2-lookbook__chapter-head > p` outranked `.sr2-lookbook__number`). Fixed with a parent-qualified selector. Verified `lookbook-section-1440-02.png`, `-04.png`.
3. Account preview lacked the `<div class="woocommerce">` wrapper the `woocommerce_account` shortcode emits, so login rows rendered inline and the dashboard grid did not apply. Wrapper added in `template-parts/v2-commerce-preview.php`; `.password-input { display:block }` + `.show-password-input { position:absolute }` added in the account block (Woo core CSS sets both in production; fixture has no Woo CSS). Verified `account-1440.png`, `account_state_dashboard-1440.png`.
4. Cart: duplicate hairline under the head removed; "Proceed to checkout" no longer underlined. Verified `cart-390.png`.
5. Woo notice group on cart/checkout now has band spacing under the fixed header. Verified `checkout-submitted-empty-1440.png`.
6. Native checkbox/radio controls in checkout/account/track-order sized to 1.25rem and vertically centred.
7. Journal index (`index.php`) h1 was the site name; now "Journal" for `is_home()`.
8. Collections index: per coordinator, `page.php` now renders Agent B's `template-parts/collections/index` (h1#sr2-page-title + four `.sr2-chapter` lockups). My interim `template-parts/pages/collections-index.php` and its `.sr2-collections-chapter*` rules in `content-page.css` were orphaned and removed. Verified `collections-1440.png`, `collections-390.png` with scroll-dwell.

## Capture artifacts ruled out as theme defects [repro]
- Earlier full-page captures showed solid accent blocks where lazy chapter scenes sit (collections chapters 02–04, about Blox). Programmatic 700 px `scrollTo` jumps never fired the theme's IntersectionObserver in headless Chromium; `scrollIntoView` on the same figure adds `is-seen` immediately (`::after` → `scaleX(0)`). Capture now scrolls each reveal target into view; the blocks are gone at both widths.
- The first reduced-motion pre-order capture showed an empty product-card frame: the `loading="lazy"` garment image had not loaded before the screenshot. Probed in both motion preferences: `sg-005-480w.webp`, `complete: true`, `naturalWidth: 360`, opacity 1. Capture now dwells on visible lazy images; `pre-order-1440-reduced-motion.png` shows the garment.
