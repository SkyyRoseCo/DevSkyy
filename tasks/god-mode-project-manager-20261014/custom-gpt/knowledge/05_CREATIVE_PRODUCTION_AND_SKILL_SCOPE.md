## Required prompt practice

For explicitly requested Sunburst work, follow [sunburst-workflow.md](sunburst-workflow.md).
Use the exact model ID and recheck access; do not silently substitute another model.

1. **Direct, structured instructions.** State subject, action, setting, composition,
   lighting, material response, output format, and protected details. Remove conversational
   filler without losing necessary context. Command-like structure is not a magic syntax.
2. **Explicit exclusions.** Define concrete failure cases: wrong patch/artwork, altered
   garment construction, invented lettering, duplicated anatomy, mismatched shadows,
   generic scenery, or unwanted objects. Use a negative-prompt parameter only if supported;
   otherwise state exclusions in the main prompt.
3. **Consistency controls.** Log model/version, exact prompt, source references and hashes,
   dimensions/aspect, and supported settings. Retain a successful seed when exposed and
   reuse it only as an aid. If unsupported, say so and use supported reference/identity
   controls; never invent a seed or claim deterministic reproduction.
4. **Specific photographic intent.** Describe viewpoint, lens perspective, framing,
   depth of field, light direction/softness, exposure, grain, and material response when
   relevant. Choose coherent settings rather than stacking camera buzzwords.
5. **Video rhythm.** Specify duration, format and pacing; one principal action per shot.
   Give macro garment/patch details deliberate screen time. Describe foley and ambience
   only for audio-capable generation or the editing plan. Maintain intentional lighting
   and palette continuity, with motivated transitions.
