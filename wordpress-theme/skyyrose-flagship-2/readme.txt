SkyyRose Flagship 2 is an Oakland-rooted editorial WooCommerce theme with collection story worlds and progressive cinematic presentation.

== Description ==

The theme provides a complete storefront route structure for WooCommerce,
collection-specific editorial pages, service pages, a Journal, wishlist shell,
right-to-left support, editor styles, and an explicit one-click demo-structure
importer. WooCommerce remains the authority for product, price, stock, cart,
checkout, customer, order, and payment state.

No product or inventory data is fabricated by the demo importer. Existing
pages and populated navigation menus are never overwritten.

== Installation ==

1. Install and activate WooCommerce.
2. Upload and activate SkyyRose Flagship 2.
3. Open Appearance → SkyyRose V2 Setup.
4. Run the demo-structure importer once.
5. Import the authorized catalog through the merchant’s separate WooCommerce workflow.
6. Configure payments, tax, shipping, email, privacy, and policy settings before accepting orders.

== Frequently Asked Questions ==

= Does the theme create products? =

No. Products and product media must enter through an authorized WooCommerce and SkyyRose SOT workflow.

= Can I run the importer more than once? =

Yes. It is idempotent and reuses exact existing pages and menus without replacing merchant content.

= Does cinematic motion block shopping? =

No. Motion is progressive enhancement. Purchase controls and route links remain available with JavaScript disabled or reduced motion enabled.
